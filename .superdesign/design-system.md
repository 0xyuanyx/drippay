# DripPay Superdesign 제약

## 화면 목적

하나의 홈 화면에서 ‘내 포인트가 시간에 따라 어떻게 귀속되는가’를 3초 안에 읽게 한다.

## 필수 요소

- 로컬 Hardhat 네트워크 상태, 포인트 잔액, 지갑 주소가 있는 상단 바
- DripPay 보관 금액 / 받을 돈 / 남은 예치금의 세 요약 수치
- 가로형 정산 행: 서비스 아이콘, 역할, 정산된 포인트, 진행률
- 숨긴 계약을 다시 표시하는 비파괴적 관리 UI

## 컴포넌트 규칙

- `metric-grid`: 세 열, 동일 높이, 얇은 구분선
- `settlement-row`: 넓은 데스크톱에서 다섯 열, 모바일에서 역할 우선
- `detail-actions`: 12px 간격, 모바일 세로 배치
- `archive-button`: 중립 윤곽, 위험 버튼처럼 보이지 않음

## 스타일 제한

Pretendard, 딥 그린과 오프화이트, 1px 구분선, 가벼운 11–18px radius. 그림자는 다이얼로그에만 제한적으로 사용한다.
