# DripPay 디자인 시스템

`LANGUAGE=ko` · `VARIANCE=4` · `MOTION=3` · `DENSITY=7`

## 제품 인상

차분한 금융 도구처럼 보이되, 차갑거나 과도하게 블록체인스럽지 않게 만든다. 사용자는 ‘정산이 진행 중’이라는 사실을 숫자와 미세한 흐름으로 이해해야 한다.

## 레이아웃

- 최대 콘텐츠 폭은 1180px, 바깥 여백은 데스크톱 24px 이상이다.
- 상단 바는 브랜드와 네트워크·포인트·지갑 상태를 한 줄에 담는다.
- 카드보다 얇은 선과 넉넉한 여백으로 정보 영역을 나눈다.
- 요약 수치는 3열, 계약 행은 역할·정산 포인트·진행률을 분리한다.

## 상호작용

- 주 행동은 진한 녹색 버튼, 파괴적 행동은 연한 적색 윤곽 버튼이다.
- 취소된 계약의 숨기기는 중립 윤곽 버튼으로 둔다. 삭제처럼 보이게 하지 않는다.
- 진행 막대의 작은 흐름 효과는 시간 비례 정산의 메타포이며, 숫자보다 앞서 의미를 과장하지 않는다.
- 모든 비활성 버튼은 투명도와 `not-allowed` 커서를 함께 쓴다.

## 금지 사항

- OTT 브랜드 로고·계정 제공을 암시하는 화면
- 과한 그림자, 블루·퍼플 네온 그라데이션, 순수 검정 배경
- 색상만으로 상태를 구분하는 표현
- ‘자동 송금 완료’처럼 실제 컨트랙트 동작보다 강한 문구

## 셀프 크리틱 / Pre-flight

- [x] 메인 헤드라인은 특정 OTT가 아니라 개인 정산 상태다.
- [x] 한국어 줄바꿈은 `keep-all`을 사용한다.
- [x] 숫자는 역할별로 분리되어 비교 가능하다.
- [x] 모바일에서 우선순위가 낮은 열을 숨겨 가로 스크롤을 방지한다.
- [x] 취소된 계약은 숨길 수 있으나, 블록체인에서 삭제된다고 표현하지 않는다.
