# DripPay 대시보드 설계

## 설계 원칙

홈은 OTT 탐색이나 파티 매칭 화면이 아닙니다. 사용자는 “내 포인트가 지금 어디에 있고, 얼마나 흘렀는가”를 먼저 봐야 합니다.

## 화면 구조

```text
┌─────────────────────────────────────────────────────────────┐
│ DripPay                              네트워크 · P · 지갑     │
├─────────────────────────────────────────────────────────────┤
│ 안녕하세요.                                      새 정산 만들기 │
│ 로컬 체인에 기록된 내 정산을 확인하세요.                       │
│                                                             │
│ [DripPay 보관 금액] [받을 돈] [남은 예치금]                  │
│                                                             │
│ 시간이 흐르는 계약                                      N건 │
│ [아이콘] 서비스  [파티장/파티원] [정산된 P] [진행률]  →     │
│                                                             │
│ 숨긴 정산 N건 보기                                           │
└─────────────────────────────────────────────────────────────┘
```

## 핵심 정보

| 요소 | 의미 | 문구 원칙 |
| --- | --- | --- |
| DripPay 보관 금액 | 아직 정산 계약 안에 남은 총 포인트 | ‘컨트랙트’보다 사용자의 이해를 우선 |
| 받을 돈 | 파티장이 지금 출금할 수 있는 금액 | 행동 가능한 금액만 표시 |
| 남은 예치금 | 파티원이 중단 시 돌려받을 금액 | 미래 기간을 보호한다는 의미 |
| 정산된 포인트 | 초 단위 추정 누적 경과분 | 작은 값도 `0.0154P`처럼 보임 |
| 진행률 | 총 기간 중 지난 비율 | 1% 미만은 소수 넷째 자리까지 표시 |

## 정산 행

한 줄은 다음 순서로 읽힙니다.

1. 서비스 종류를 빠르게 구분하는 문자 아이콘
2. 서비스명과 현재 내 역할: `파티장`, `파티원`, 또는 `파티장 · 파티원`
3. 누적 정산 포인트
4. 진행률
5. 상세 진입 화살표

정산 번호는 사용자의 의사결정에 필요하지 않아 홈에서는 노출하지 않습니다.

## 취소된 정산

블록체인 기록은 삭제할 수 없습니다. 대신 취소된 상세 화면의 `목록에서 숨기기`는 브라우저 로컬 목록에서만 감춥니다. 홈의 `숨긴 정산 N건 보기`에서 언제든 `다시 표시`할 수 있습니다.

## 반응형 규칙

- 데스크톱: 역할, 정산된 포인트, 진행률을 각각 열로 분리합니다.
- 모바일: 정보가 넘치지 않도록 서비스와 역할을 우선하고, 상세에서 금액·진행률을 확인합니다.
- 숫자는 우측 정렬하고, 상태는 색뿐 아니라 텍스트로도 표기합니다.
